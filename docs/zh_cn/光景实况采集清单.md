# 篠澤広【光景】实况：识别缺口与首轮采集清单

制定日期：2026-10-28。GHL（gakumas-headless-lab）将以决策模型 v3 实况培育篠澤広【光景】（理性·干劲，初 LEGEND）。本文列出外部决策链路（`tools/decider/ghl_readings.py`、`ghl_frame.py`）读这位偶像时的缺口，以及首轮实况结束后应保留的画面，供之后补模板。具体轮次、截图与核对结果保存到 Git 忽略的 `debug/`。

## 现状

- **手牌**：固有技能卡「本気の趣味」（库 id 232）与「本気の趣味+」（233）在 `assets/data/produce_skill_cards.json` 中。手牌按名称 OCR 查库，不需要模板；读不出的位置为「?」，GHL 用同一回合的下一帧补齐。
- **P 道具**：固有 P 道具「みちくさ研究ノート」（57）与「みちくさ研究ノート+」（58）在 `produce_reward_items.json` 中。战斗画面不读 P 道具；GHL 从替身 profile 得到开局的固有 P 道具（才能开花 2，即 58），它也不会作为奖励出现。行动选择画面右侧的 P 道具栏读取已登记模板的 P 道具（`week.items`，模板见 `battle_buff_templates.json` 的 `items`）：账号支援卡第一个事件给的天川ラーメン巡り（82，Vo 回合开始时技能卡使用数 +1，一场一次）与星のリトルプリンス（72，Vi 回合开始时固定元气 +2）。事件时机每轮不同，GHL 由此得知何时持有。该栏只显示前四个，其余折叠。
- **饮料**：理性与通用的 16 种饮料都有图标模板，包括两种干劲饮料ホットコーヒー（6，干劲 +3）与厳選初星ブレンド（24，回合结束时干劲 +1）；初星水（1，得分 +10）与フレッシュビネガー（11，手牌强化、固定体力 +3）的模板于 2026-10-30、おしゃれハーブティー（16，得分 + 好印象、元气 +3）的模板于 2026-11-01 从实况帧补上（见「之后补模板」）。
- **Buff 与 HUD**：干劲、元气、体力、剩余回合与考试回合属性的读取与十王星南相同，不依赖偶像。

## 没有模板的饮料

读取器按请求的饮料候选框把该槽位记为「?」，读取照常完成，其余槽位与手牌不受影响（`ghl_frame.py` 的 `drink_names`）。GHL 的牌组账本用跟踪的饮料推断「?」槽。实况桥原先不在「?」槽提供饮料选项；自 GHL `a4e6cb3` 起，画面未写名的饮料与「?」槽一样多且是同一种饮料时，桥在该槽提供它（2026-10-30 的决赛中，决策模型想用フレッシュビネガー的 7 个决策都因此用不到它）。

## 首轮实况应保留的画面

每条决策请求的截图都在信箱的 `frames/` 中；考试结果与结算画面由采集（`config/decision_capture.json`）和 GHL 启动器的结束画面监视保存。实况结束后先整体归档信箱、`debug/decision_capture/` 与 `debug/produce_sessions/`，再按下表找画面：

| 用途 | 画面 | 来源 |
| --- | --- | --- |
| 初星水、フレッシュビネガー、おしゃれハーブティー的图标模板 | 持有该饮料的每场战斗的首帧（饮料槽区域 `[10, 1150, 280, 100]`） | 战斗请求，自动 |
| 上述饮料的身份依据 | 获得该饮料的奖励（或开局奖励）请求，以及之后饮料保留对话框中的效果文字 | reward、drink_keep 请求，自动 |
| 本気の趣味的名称识别 | 手牌中有本気の趣味或本気の趣味+ 的战斗帧 | 战斗请求，自动 |
| P 道具计数（尚未实现，留作素材） | 最后两回合开始后的第一帧：みちくさ研究ノート+ 触发后的得分与体力 | 战斗请求，自动 |
| 初 LEGEND 的结算识别 | 期中与最终考试的结果、最终评价与三维 | 采集与结束画面监视，自动 |

从未在战斗中持有的饮料没有可裁切的画面，保留为缺口。
